# ⚙ KIP Control Center

Легковесный и современный центр управления системой с поддержкой динамических плагинов, написанный на Python (FastAPI) и современном фронтенде.

##  Ключевые особенности

* **Современный UI/UX:** Строгий тёмный интерфейс в минималистичном стиле с поддержкой карточной структуры и отзывчивых элементов.
* **Динамические плагины:** Архитектура `code-first` на базе легкого SDK. Плагины автоматически сканируют свои методы и рендерят интерфейс без изменения основного кода.
* **Мастер настройки (Onboarding Wizard):** Удобный мастер первого запуска с пошаговой конфигурацией сети и встроенной документацией.
* **Широкий набор виджетов:** Поддержка кнопок, групп кнопок, слайдеров, выпадающих списков и тумблеров «из коробки».

## Быстрый старт в обычном запуске (только Windows)

**Скачайте последнюю версию проекта**

   Скачать можно тут:  https://github.com/mntlxx/kip/releases

После первого запуска автоматически откроется страница с первоначальными настройками, так что вам ничего даже не нужно будет делать. Однако есть одна особенность: если в трее IP подключения не поменялся, тогда нажмите на кнопку "Перезапустить Kip", чтобы поменялся IP для подключения. Да, иногда такое случается.
